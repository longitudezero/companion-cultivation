Rune hover sounds — split from `runes hovering.wav`

352 individual xylophone strikes, numbered in source order.
Each file starts just before its strike and ends after the note decays, with short anti-click fades.
WAV: 44.1 kHz, stereo, 16-bit PCM (best for editing and broad compatibility).
OGG: 44.1 kHz, stereo, Vorbis compressed (smaller game assets).
Names: rune_hover_001 to rune_hover_352.
manifest.csv maps each file to the approximate start time in the original audio.
These sounds are one-shots: trigger a file when the cursor enters a rune; avoid triggering continuously every frame.

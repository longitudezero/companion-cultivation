## How to reproduce and interpret

- Use the original **entire design source**, retaining original line breaks, not an intermediate reorganized copy.
- Exclude Markdown ATX heading lines; select each remaining line with at least one decimal digit and at least three characters.
- First check for an **exact full-line** occurrence in the active topical drafts and the historical appendix, classifying mutually exclusively: active only, historical only, both. Only unmatched lines are rechecked after replacing `](*.md)` path destinations with a common placeholder on both sides.
- The four path-only cases occur in the source opening, §14, §61 and §64. The line content still matches when destinations are normalized.
- A zero in the “Unaccounted” column **does not imply the operative behavior is correct**. Old proposal text is intentionally available as history. This ledger does not cover spelled-out quantities without numerals or non-numeric constraints.

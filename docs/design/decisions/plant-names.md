# Plant naming pass — approved and implemented

These are **old identifiers → current names**. Read each row as a single identity; do not recursively rename names that also appear elsewhere in the old column.

## Compatibility and documentation

- New games use garden schema **V7**, with the current names in the registry, player interface, inventory, Grimoire, and recipes.
- Loading a **V6** autosave or downloadable garden translates old identifiers **once** before rehydration, including living Plants, pending/staged Seeds, stock and Leaf identities, inventory layout, transformation progress, and witnessed Grimoire facts. New V7 saves are not translated again. Versions earlier than V6 remain incompatible for unrelated historical fungal-schema reasons.
- The original family design profiles and V9 recipe tables retain the names they used when approved, preserving their design provenance. This document is the naming overlay for those older references; it does not revise the mechanics.
- The future store/progression design now refers to **Beanstalk Seeds** as the free base-Ingredient recovery route, formerly called Potato Seeds.

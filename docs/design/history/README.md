- [Original complete Herbs and Fungi design](../../herbs-and-fungi-design.md) — unchanged full source for exact comparison, including §76.
- [Original root README snapshot](root-readme-before-promotion.txt) — byte-for-byte copy of the README before the new documentation index was added. Git history also retains the original.

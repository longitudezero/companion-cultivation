## Scope boundary

Publishing a coherent, navigable first-pass design specification does **not** implement its Plant/Fungus/Mycelial systems or resolve their remaining game-design choices. Exact fungal lifecycle/Spore economy, physical route geometry, board feasibility, simulation tests and numerical playtesting belong to later design/engineering work.

# Historical reference and original-source preservation

The originals in the repository's existing docs folder are **left completely untouched** during this migration. These files are supporting history, not the canonical design:

- [Superseded design material](superseded-design.md) — source §§1–21, 45–46, 51–52 and the incomplete §75 record, including the specific supersession index.
- [Original Environmental System v1.1](../../environmental-system-v1.1.md) — four-Property historical specification (the current version is [v1.2](../systems/environment.md)).
- [Existing conversation handoff](../../conversation-handoff.md) — chronological status and approvals; its older status statements are not authoritative over the latest sections.
- [Original complete Herbs and Fungi design](../../herbs-and-fungi-design.md) — unchanged full source for exact comparison, including current §76.

See [coverage crosswalk](../audit/source-crosswalk.md) to find where each source section was copied.


The historical design archive also includes **section-labeled, verbatim excerpts** removed from newly staged topic files during the second editorial pass. These include superseded Woodlands/Mycelial and Waterborne values, obsolete Material/Fertility assumptions, early roster counts and deferred-recipe claims. See the [original-versus-new comparison](../audit/current-vs-original.md) for the preservation checks.
